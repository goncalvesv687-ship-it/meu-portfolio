Projeto 1: Rede de Hotéis

Este projeto apresenta o modelo conceitual de um Banco de Dados para uma Rede de Hotéis, desenvolvido a partir de regras de negócio específicas. O objetivo é criar uma estrutura de dados robusta e eficiente que permita gerenciar funcionários, unidades hoteleiras, quartos, hóspedes, reservas e pagamentos.
